# MudPlayer

Десктопный плеер: единый поиск по SoundCloud, YouTube Music и Audius, импорт из Spotify и SoundCloud, «Моя волна», синхронные тексты (LRCLIB), Dynamic Island поверх всех окон.

## Импорт
Медиатека → Плейлисты → поле «Импорт»:
- **SoundCloud**: ссылка на профиль (`soundcloud.com/ник`) подтянет лайки и все плейлисты; можно и ссылку на отдельный плейлист.
- **Spotify**: ссылка на публичный плейлист или альбом (по ссылке Spotify отдаёт до 100 треков).
- **Весь Spotify, включая «Любимые треки»**: зайди на exportify.net, войди через Spotify, скачай CSV и загрузи кнопкой «CSV».
Треки из Spotify играют через автоматически подобранную полную версию (сначала SoundCloud, потом YouTube Music; учитываются название, артист и длительность). Совпадения запоминаются.

## Установка как обычного приложения (Windows)
Двойной клик по **`build-exe.bat`** — он один раз соберёт установщик и запустит его.
Установщик поставит MudPlayer, создаст ярлык на рабочем столе и в «Пуске». Дальше просто запускаешь MudPlayer с ярлыка; папку проекта можно удалить.
Нужен Node.js 20+ (https://nodejs.org) — он же служит yt-dlp для YouTube.

## Запуск без установки
`start.bat` (или `npm install` → `npm start`).

## Горячие клавиши
Space — пауза · ← → — ±5 с · N / P — следующий / предыдущий · L — текст на весь экран · [ ] — сдвиг текста на 0,25 с · Ctrl+K — поиск · Esc — закрыть.
Медиа-клавиши клавиатуры и оверлей громкости Windows работают через MediaSession.

## Как устроено
- `main/main.js` — главный процесс: yt-dlp (скачивается сам), поиск (youtubei.js → запасной путь через yt-dlp), SoundCloud через yt-dlp, Audius по открытому API, локальный прокси `127.0.0.1` с поддержкой Range (перемотка), LRCLIB, окно островка.
- `renderer/src/app.jsx` — интерфейс (React). Собранный `renderer/renderer.js` уже лежит в проекте.
- Пересборка интерфейса после правок: `npm i -D esbuild react@18 react-dom@18` → `node build.mjs`.
- Журнал: `logs/main.log` (кнопка в Настройках).

## Если YouTube перестал играть
Настройки → yt-dlp → «Обновить». YouTube часто меняет защиту, свежий yt-dlp обычно это чинит.
Скачивание с YouTube через yt-dlp нарушает правила YouTube — проект для личного использования.
